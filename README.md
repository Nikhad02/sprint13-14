# Планировщик задач (Todo List API) — Спринт 13-14

Веб-приложение для автоматизации планирования задач. Сервис позволяет создавать задачи, просматривать их списком и настраивать гибкие правила повторения (каждый день, через определенное количество дней, в конкретные дни недели или месяца).

**Основные фичи бэкенда:**
* REST API на языке Go с использованием стандартной библиотеки `net/http`.
* Полноценная валидация входящих дат и правил повторения по ТЗ.
* Хранение и управление данными в реляционной БД SQLite.
* Безопасность доступа, построенная на механизме JWT-токенов.

## Инструкция по локальному запуску (без Docker)

1. **Настройка окружения:**
   Задайте секретный пароль для авторизации через терминал.
    * *Для macOS / Linux:*
      ```bash
      export TODO_PASSWORD="your_secret_password"
      ```
    * *Для Windows (PowerShell):*
      ```powershell
      $env:TODO_PASSWORD="your_secret_password"
      ```

2. **Запуск сервера:**
   Убедитесь, что папка `web` находится в корне проекта, и выполните:
   ```bash
   go run main.go
   
3. **Доступ к приложению:**
   Откройте браузер и перейдите по адресу: http://localhost:7540/login.html
   (Для входа введите пароль, который вы указали в переменной окружения выше).

## Инструкция по запуску тестов

1. Запустите веб-сервер (локально или внутри Docker).
2. Перейдите на страницу авторизации http://localhost:7540/login.html и успешно авторизуйтесь с вашим паролем.
3. Откройте инструменты разработчика в браузере (F12) -> вкладка **Application** (в Chrome/Edge) или **Storage** (в Firefox) -> в левом меню раскройте пункт **Cookies**.
